# osd-formats

Open Synth Descriptors (OSD) to and from the formats others use: MIDI CSV tables, Electra One, MIDNAM and OSCQuery. It builds on the reader [`osd`](https://crates.io/crates/osd) and says what a format cannot carry.

```toml
[dependencies]
osd-formats = "0.1"
```

See the [repository](https://github.com/roomi-fields/open-synth-descriptors) for the format.
