## What it changes

The text of 0.7, or a later one: how a resolving reader, given a descriptor read from a web address, finds the root of the catalogue that holds the files it links to.

## Why

A resolving reader asks its source of files for each descriptor a device links to (`docs/ARCHITECTURE.md`, section 5). From a folder the root is the folder given; from a web address nothing says where the root is.
