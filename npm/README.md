# @roomi-fields/osd

The `osd` command of [Open Synth Descriptors](https://github.com/roomi-fields/open-synth-descriptors).

```sh
npm install -g @roomi-fields/osd
osd --version
```

At install, the package downloads the binary of your platform (Linux x86_64, macOS arm64 or x86_64, Windows x86_64) from the GitHub release of its own version and checks its SHA-256 against the release's `SHA256SUMS`; a different checksum is refused.
