# Security

To report a vulnerability in the `osd` reader, the `osd` command or the npm
package, use GitHub's
[private vulnerability reporting](https://github.com/roomi-fields/open-synth-descriptors/security/advisories/new)
of this repository. Do not open a public issue for it. The maintainer reads the
report; no e-mail address is published.

Describe what you did, what you saw and which version of `osd` you used. The
project is maintained by one person and sets no delay for an answer.

A defect that is not a vulnerability goes to the
[issues](https://github.com/roomi-fields/open-synth-descriptors/issues).
