# osd-cli

The `osd` command of [Open Synth Descriptors](https://github.com/roomi-fields/open-synth-descriptors): validate, convert, start, import and export a descriptor file.

```sh
cargo install osd-cli
osd --version
osd validate my-device.json
```

Ready binaries (Linux, macOS, Windows) and the npm package `@roomi-fields/osd` install the same command; the repository README gives the three ways.
